# From Information Requirements to Knowledge Graphs: ## A Semantic Approach Based on DD, DT, and LOIN

**Authors:** Peter Johansson, Nischal Bhattarai, Rahel Kebede, Annika Moscati  
**Affiliation:** Department of Construction Engineering and Lighting Science, Jönköping University, Sweden

## Overview

This repository contains the data, models, semantic representations, mappings, and scripts developed and used in this research.

The work investigates how standards for Data Dictionaries (DD), Data Templates (DT), and Level of Information Need (LOIN) can be operationalised using Semantic Web technologies and Knowledge Graphs to support interoperability and machine-readable validation.

A lighting fixture use case is used to connect standards-based information requirements with ontology modelling, Information Delivery Specification (IDS), RDF-based Knowledge Graph representations, and SHACL-based validation.
